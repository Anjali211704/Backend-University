# Task 4 - Sessions, Cookies and Query Strings

## Aim

To understand how query strings, cookies and sessions are used in backend development using Node.js and Express.js.

This task demonstrates how data can be passed through the URL, stored in the browser and remembered on the server across multiple requests.

---

## Concepts Covered

- Query Strings
- Cookies
- Sessions
- Express.js Routes
- Request and Response Objects
- Server-side State Management
- Browser-side Data Storage
- Session Tracking

---

## Technologies Used

- Node.js
- Express.js
- express-session
- cookie-parser
- JavaScript

---

The following packages are required for this task:

npm install express express-session cookie-parser
