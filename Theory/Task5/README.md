# Task 5 - LocalStorage, SessionStorage and JSON

## Aim

To understand how LocalStorage and SessionStorage are used to store data in the browser and how JSON is used to convert and exchange structured data in JavaScript applications.

This task demonstrates basic browser storage operations such as saving, retrieving and deleting values.

---

## Concepts Covered

- LocalStorage
- SessionStorage
- Browser Storage
- JSON
- JavaScript Objects
- JSON.stringify()
- JSON.parse()
- DOM Manipulation
- Storing and Retrieving Data

---

## Technologies Used

- HTML5
- JavaScript
- Web Storage API
- JSON

No additional package installation is required for this task.
