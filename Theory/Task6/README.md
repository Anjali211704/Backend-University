# Task 6 - Server-Side Rendering using EJS and Jinja2

## Aim

To understand the concept of Server-Side Rendering (SSR) and implement it using two template engines:

- EJS with Node.js and Express
- Jinja2 with Python and Flask

The task demonstrates how backend applications can generate dynamic HTML pages by inserting server-side data into HTML templates.

---

## Concepts Covered

- Server-Side Rendering
- Template Engines
- Dynamic HTML
- EJS
- Jinja2
- Express.js
- Flask
- Passing Backend Data to Templates

---

## Technologies Used

### EJS Application

- Express.js

### Jinja2 Application

- Python
- Flask
- Jinja2
