# Experiment 3 - Responsive Web Design

## Aim

To design a responsive webpage that automatically adjusts its layout according to different screen sizes.

## Concepts Used

- Responsive Web Design
- Viewport meta tag
- CSS Flexbox
- Media Queries
- Desktop layout
- Tablet layout
- Mobile layout

## Breakpoints Used

- 768px for tablet devices
- 480px for mobile devices

## Files Used

- index.html
- style.css

## Output

A responsive webpage was created which changes its layout according to the width of the screen.

## Conclusion

This experiment helped me understand how media queries and flexible layouts can be used to make webpages responsive for desktop, tablet and mobile devices.
