# Experiment 1 - HTML5 Elements

## Aim

To study and implement different HTML5 elements used for structuring and displaying content on a webpage.

## Elements Used

- Heading tags
- Paragraph tags
- Semantic tags
- Navigation links
- Text formatting tags
- Ordered list
- Unordered list
- Description list
- Table
- Form
- Input elements
- Select dropdown
- Textarea
- Checkbox
- Radio buttons
- Article
- Details and Summary
- Footer

## Output

A webpage was created demonstrating commonly used HTML5 elements.

## Conclusion

This experiment helped me understand the basic structure of an HTML5 webpage and how different HTML elements are used to organize content, create forms, tables, lists and interactive sections.# Experiment 1 - HTML5 Elements
