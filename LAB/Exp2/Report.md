- External CSS

- Class selectors

- Background colors
- Text colors
- Padding
- Margin

- Border radius

- Button styling

## Output

A styled webpage was created using external CSS.

This experiment helped me understand how CSS is used to improve the appearance and layout of a webpage. I also learned how external CSS files can be linked with HTML and how Flexbox can be used for arranging elements.
