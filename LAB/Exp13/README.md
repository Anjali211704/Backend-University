# Experiment 13A - Express + Mongoose User Management

## Aim

To create a simple User Management System using Node.js, Express.js, MongoDB Atlas, and Mongoose.

The application allows users to:

- Register a new account
- Login using username and password
- View all registered users
- Store user information permanently in MongoDB

---

## Concepts Used

This experiment demonstrates the basic working of:

- Node.js
- Express.js
- MongoDB
- MongoDB Atlas
- Mongoose
- MongoDB Schema
- MongoDB Model
- Express Routes
- GET and POST requests
- Async/Await
- Environment Variables
- Basic Error Handling

---

## Technologies and Packages

### Node.js

Node.js is used to execute JavaScript on the server side.

### Express.js

Express is used to create the web server and handle different routes.
